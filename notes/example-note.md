# 示例笔记

这是一个示例笔记页面。

## 插入图片

把图片放到 `assets/images/` 目录下，然后用以下语法插入：

```markdown
![图片说明](/OSOCRestartNotes/assets/images/图片文件名.png)
```

### 示例

```markdown
![代码截图](/OSOCRestartNotes/assets/images/screenshot.png)
```

> **注意**: 路径要以 `/OSOCRestartNotes/` 开头（仓库名），这是 GitHub Pages 的 URL 路径。

## 支持的图片格式

- PNG (.png)
- JPG (.jpg)
- JPEG (.jpeg)
- GIF (.gif)
- SVG (.svg)
- WebP (.webp)
